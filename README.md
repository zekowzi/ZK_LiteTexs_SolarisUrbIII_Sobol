# #LiteTexs - UrbinoIII Sobol
Un réupload de plus: les LiteTexs pour les Urbino III de Sobol. Comme toujours, installation simplifiée (juste à glisser l'archive dans le dossier adapté (steamapps/common). Les versions antérieures à la 3.00pa2 est requise, et le mod est disponible sur le Patreon de Sobol.

# Notes
Ne vous fiez pas au nom LiteTexs Urbino IV Sobol dans l'archive : je me suis planté de gen lors de la confection de l'archive !

# Installation
Winrar ou alternatives requise. Glissez le contenu de l'archive dans le dossier steamapps/common.
